# Regular expression search

Regex mode uses the host WebView's ECMAScript Unicode regular expressions (`u`, `g`, and capture indices `d`; `i` unless Match case is selected). Patterns support the engine's lookaround and pattern backreferences; syntax errors are shown in Find. Anchors and `.` have JavaScript defaults: `^`/`$` apply to the searched segment, and `.` does not match newlines. Use constructs such as `[\s\S]` for multiline matching; inline flag syntax is only available if the host engine supports it. Whole word uses Unicode letters, numbers, marks and underscore at the match boundaries.

A disposable worker runs each regex and is terminated after 500 ms, including worker startup. The pattern is limited to 1,024 UTF-16 units, searched text to 1,000,000 UTF-16 units, captures to 64, text segments to 10,000, and results to 2,000. Captured values and result metadata share a 1,000,000-unit budget, including named duplicates; exceeding it discards all results. The result cap is conservative: reaching it is reported as `2000+` and Replace All is disabled. Timeouts, invalid syntax, unsupported engine features and size limits are visible errors; no partial results are applied on error. Worker isolation and termination protect UI responsiveness but do not constitute a hard process-memory limit.

Captures show numbered, patterned color underlines and a textual group legend. Colors/patterns repeat after six groups; overlapping and nested captures may visually overlap. Unmatched groups have no range; zero-width matches remain navigable but cannot be underlined. Search advances a zero-width match by one Unicode code point. All positions are UTF-16 units, as required by the editors.

Replace supports `$$` (literal dollar), `$&` (whole match), `$1` through `$99` and `$<name>`; an existing unmatched group expands to empty text, while unknown references remain literal. Replacement text is not interpreted as a regex. Replacement templates are limited to 64,000 UTF-16 units, aggregate expanded output to 16,000,000 units, and expansion work to 1,000,000 capture-token evaluations. The entire operation is checked before editing; exceeding a limit reports an error without changing the document. Replace All is one undo event. An asynchronous result belongs to its exact query, options, active document and editor document; a changed owner or engine document invalidates it.

Source mode searches CodeMirror's entire document, including folded notation. Rendered mode searches text within each textblock and stops at atoms, hard breaks and block boundaries. Inline marks do not split a segment; literal code text is searchable, while diagram/image atom internals are not. Regex patterns and replacements never change a document until an explicit replacement action. Rendered edits may normalize Markdown in the same way as other genuine rendered edits.
