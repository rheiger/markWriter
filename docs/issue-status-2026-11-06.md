## Completed alpha3 scope

- **#38:** Theme-aware toolbar and synchronized Auto/Light/Dark controls; theme/view changes preserve document state.
- **#40:** Shared offline highlighting across both editors, Preview and HTML export, all original requested languages plus CSS/Swift/Makefile and Objective-C `m`; saved synchronized toggle. The registry has 19 variants/18 grammars (Zsh uses Bash).
- **#39:** Original missing-icon request complete with editable paper/brass-nib artwork, native assets, installed resource/launcher wiring and strict Mac ad-hoc bundle integrity. Expanded About retains the exact Richie credit. Broader shell/cache/upgrade visuals remain unchecked; optional Finder automation was inconclusive and original Finder view restoration was not verified.
- **#45:** Technical editing-host policies and queued replacement guards, native literal punctuation/Unicode checks in both editors. Arbitrary OS spelling/text-expansion configurations remain unqualified; active prose spelling correction did not trigger.

Richard explicitly deferred Java/Perl/AWK/sed/CMake and broader practical autodetection to #44. Existing detection is limited; closing #40 does not promise reliable unlabeled-language identification. #46 separately records pre-existing repeated-space loss during inline-code WYSIWYG serialization.

## Recommended next increment

#47–50 now include proposed acceptance, dependencies and explicit implementation boundaries, with their original requests retained. They remain open; this refinement does not ship those features.

Prioritize **#46 whitespace fidelity**, then scope the new high-priority **#50 mathematical notation** with a representative fixture and explicit editing/Preview/export behavior. Pair this with **#47 user Help**, so users can discover supported conventions and known limits. Keep #44 as an independently bounded follow-up. Treat **#48/#49 native Quick View/registration** as a separate platform integration slice; expanded About and package icons do not implement it.

PDF#41 still needs actual paginated-file/backend feasibility across native targets. Qualify DBML#33 before SQL DDL import#42; declare a dialect and fixture first. Preserve canonical Markdown, dirty/history state, captured-document I/O, recovery, folds/navigation/search and independent source/rendered fonts. New formats need their own offline/native/safety/persistence/export gates.
