## Delivered behavior

Canonical `dot` and alias `graphviz` fences render offline in Preview and opaque WYSIWYG atoms. Insert → Diagram → DOT, source folds/search, explicit block correspondence, undo, save/reopen/recovery and static SVG/HTML export use the same qualified renderer. View-only actions preserve canonical source/clean state; actual rendered edits retain graph and surrounding prose, including unmatched and CR-only fence boundaries. Mermaid, tables, ownership, per-tab histories, recovery/discard and independent fonts remain supported. The exact Richie credit is retained; all relevant version manifests are2.1.0-alpha2.

Pinned Viz3.31.0/Graphviz16.1.0 is bundled in a killable local worker:64KiB UTF8 input,2MiB SVG,2s layout plus5s startup,32 waiting jobs. There is no hard WASM memory bound. Strict worker response CSP permits WASM while denying connections/resource surfaces; the document gains no general eval/WASM permission. SVG is reconstructed from bounded approved geometry/text. Files/network/images/HTML labels/links/includes/CSS/gradients and unsupported attributes fail recoverably. See [ADR](adr-offline-dot.md) and [supported subset](supported-markdown.md).
