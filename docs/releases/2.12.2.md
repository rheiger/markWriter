## MarkWriter 2.12.2

- Highlight large explicit TOML fences in both Markdown and WYSIWYG. Fences that exceed the highlighting budget stay readable with their full text and a fallback notice. [Large TOML editing](https://github.com/rheiger/markWriter/issues/104)
- Explain how to recover when the selected SQL file contains NUL characters, including files saved in another encoding. [SQL import feedback](https://github.com/rheiger/markWriter/issues/105)

Download the Apple silicon macOS DMG, Windows x64 installer or Ubuntu 26.04 x64 DEB. Verify the package against `SHA256SUMS`. The macOS application and Quick Look extension use ad hoc integrity seals. The Windows installer is unsigned. [Installation, removal and rollback](https://github.com/rheiger/markWriter/blob/v2.12.2/docs/install-2.12.2.md)
