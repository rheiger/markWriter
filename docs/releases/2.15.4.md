# MarkWriter 2.15.4

This release prepares for app-controlled updates. It adds signed manifest
freshness tests, an update restart checkpoint exercised in acceptance builds,
and a repeatable Apple silicon replacement and rollback trial. On Windows,
document saves retry transient atomic replacement errors within a short
bound and stop if the file has changed on disk.

Use **Help → Check for Updates** to find the matching manual installer. **Skip
This Release** and **Remind Me Later** remain available. Production activation
requires an approved trust root and feed policy, authenticated delivery,
checkpoint-to-restart coordination, and installed Apple silicon qualification.

The Apple silicon DMG contains an ad hoc sealed editor and Quick Look extension. The Windows installer carries an Authenticode signature from a self-signed test certificate that Windows treats as untrusted by default. Verify downloads against the release’s `SHA256SUMS`.

See [installation, upgrade and rollback](../install-2.15.4.md) and the
[PI 2.15 record](https://github.com/rheiger/markWriter/issues/126).
