## MarkWriter 2.7.5

Fixes an intermittent Windows Explorer error when reopening a Markdown file in an existing MarkWriter window. Each launch gets a fresh named-pipe connection, so a previous launch can finish without interrupting the next one.

Verify downloads against `SHA256SUMS`. The macOS app and extension are ad hoc sealed. The Windows installer is unsigned. See the [installation, removal and rollback guide](https://github.com/rheiger/markWriter/blob/v2.7.5/docs/install-2.7.5.md).
