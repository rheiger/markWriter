# MarkWriter 2.5.0-alpha1

Experimental prerelease for technical writing, from `ee0b534c70ea53988a7e6263ae634e7f87d914cb` via [PR #51](https://github.com/rheiger/markWriter/pull/51). GitHub latest remains unchanged.

- Preserve meaningful inline-code spaces, tabs, whitespace-only spans and backticks through rendered editing, save/reopen and static HTML export.
- Write explicit `math` fences with bounded offline TeX-style rendering in both editors and Preview. Edit source directly in WYSIWYG with document Save/Undo/recovery; export static math with embedded fonts.
- Open Help → User Guide for searchable offline editing conventions, actual shortcuts, recovery and independent font settings.

The exact merged source passed [quality/native checks](https://github.com/rheiger/markWriter/actions/runs/42292835912), [ordinary installed packages](https://github.com/rheiger/markWriter/actions/runs/42292835918) and [tag packages](https://github.com/rheiger/markWriter/actions/runs/42295266255) on all three targets. Evidence includes 315 frontend/10 Node checks,21 macOS/Linux and 26 Windows Rust tests,48 native Windows/Linux application groups and 22 ordinary installed groups each, with 26 code cases and 20 loaded math fonts. The final Mac app's complete sealed payload matches the downloaded app tested through native dialogs, math/code editing, Help, export and recovery. See QUALIFICATION.json, platform manifests and SHA256SUMS for exact provenance and limits.

macOS is strictly ad-hoc sealed, without Developer ID/notarization trust. Windows is unsigned. Keep OS protections enabled; browser-quarantine and other OS/WebView baselines are unqualified. Read INSTALL-UPGRADE-ROLLBACK.md and keep a document/profile backup for this experimental alpha.

Math requires explicit lowercase `math` fences; inline dollars, numbering/references and arbitrary TeX packages remain deferred. Genuine rendered edits can normalize surrounding Markdown syntax. Extra grammars/detection #44, OS previews #48/#49, PDF/DBML/DDL and other backlog remain deferred. The exact Richie attribution and paper/brass-nib artwork are retained.
