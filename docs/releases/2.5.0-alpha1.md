# MarkWriter 2.5.0-alpha1 — experimental technical writing

This prerelease targets inline-code whitespace fidelity, bounded offline mathematical blocks and bundled offline Help. Publication is permitted only after the acceptance gates for the exact source pass. Final evidence is attached as QUALIFICATION.json and platform manifests.

Use explicit `math` fences for TeX-style blocks. Inline dollar math, numbering/references and arbitrary TeX packages are deferred. Existing code highlighting, Mermaid/DOT diagrams, canonical Markdown and self-contained HTML export remain supported within their documented limits.

macOS arm64 packages are ad-hoc sealed, without Developer ID trust/notarization. Windows x64 packages are unsigned. Linux package qualification is for the recorded Ubuntu 26.04 baseline. Keep OS protections enabled. This alpha is experimental and is not the stable/latest release. Read INSTALL-UPGRADE-ROLLBACK.md and verify SHA256SUMS.
