## MarkWriter 2.13.3

- Discover stable updates in the background. The app checks at startup and every 24 hours while running. You can turn off automatic checks in Settings and continue to use Check for Updates. [#112](https://github.com/rheiger/markWriter/issues/112)
- Open the matching installer download in your default browser. If the available release has no compatible installer, MarkWriter opens its official release page. Install the downloaded package manually. [#113](https://github.com/rheiger/markWriter/issues/113)
- Extend qualification for reopening a modified Markdown tab and opening multiple files from Windows Explorer, and for structured and Markdown previews in Finder. [#116](https://github.com/rheiger/markWriter/issues/116) · [#115](https://github.com/rheiger/markWriter/issues/115)

Download the Apple silicon macOS DMG, Windows x64 installer, or Ubuntu 26.04 x64 DEB. Verify the package against `SHA256SUMS`. The macOS app and Quick Look extension use ad hoc integrity seals. The Windows package is unsigned. [Installation, removal and rollback](https://github.com/rheiger/markWriter/blob/v2.13.3/docs/install-2.13.3.md)
