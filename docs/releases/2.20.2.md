# MarkWriter 2.20.2

- Choose Source, Split, read-only Preview or WYSIWYG from the View menu. Switch views on the active tab while keeping its Markdown, unsaved edits and editor histories. The offline User Guide explains each view. [#171](https://github.com/rheiger/markWriter/issues/171)
- On Windows and Linux, use the Window menu to minimize, maximize or restore, and enter or exit full screen. F11 toggles full screen. On macOS, use the system Window menu. [#171](https://github.com/rheiger/markWriter/issues/171)
- On Ubuntu GNOME Wayland, MarkWriter passes the launcher’s activation request to the running editor when Files opens Markdown. GNOME decides whether to bring the editor forward. Open With continues to reuse the owning tab and retain unsaved text. [#177](https://github.com/rheiger/markWriter/issues/177)

The Apple silicon app and its bundled Quick Look extension carry ad-hoc seals. The Windows x64 and Ubuntu 26.04 x64 packages are unsigned. Verify the downloads against `SHA256SUMS`. [Installation, removal and rollback](../install-2.20.2.md)
