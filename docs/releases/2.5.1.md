# MarkWriter 2.5.1

Regular release, published with `latest=false`. The existing latest-release pointer and all previous releases remain unchanged.

## Changes

- Longer explicitly labelled Python/JSON code blocks highlight consistently in Markdown, WYSIWYG, Preview and HTML export. Python/JSON now support 16 Ki UTF-16 units per block and a separate 32 Ki document budget. Other grammar, automatic-detection, line-length and token-count limits remain conservative. Rendering changes do not alter document text.
- README.md is the current project entry point; README-v2.md points there and preserves historical references.
- Native and ordinary installed-package acceptance includes a six-block long-code regression with both editors, Preview, export, the disabled setting and exact view-only Save As.

## Packages and verification

Apple Silicon macOS DMG, Windows x64 NSIS and Ubuntu 26.04 x64 DEB. Read INSTALL-UPGRADE-ROLLBACK.md, platform manifests, SHA256SUMS and QUALIFICATION.json for the actual source, test baselines and limits.

**Signing:** macOS is sealed ad-hoc, without Developer ID signing or notarization. Windows is unsigned. A regular release is not a claim of trusted signing, notarization, browser-quarantine acceptance or support for untested OS baselines. Keep OS protections enabled.

## Known limits

Highlighting has input/work bounds rather than a hard lexer deadline; difficult Python input can take longer and fall back to plain text. Unlabelled-code detection remains best effort. Use explicit language names for reliable requests. Actual WYSIWYG edits may normalize Markdown syntax while view-only changes preserve the canonical source. Arbitrary OS text services, broader icon/cache/upgrade visuals and independent windows remain separately qualified or deferred.

PDF, DBML/SQL DDL, PlantUML, draw.io, graphical diagram designers and plugins are not added by this release. Inline dollar math and arbitrary TeX packages remain unsupported.
