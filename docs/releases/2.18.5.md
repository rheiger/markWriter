# MarkWriter 2.18.5

- Import local UTF-8 PostgreSQL or SQLite DDL files up to 128 KiB. Generated DBML and graphics have independent limits. [SQL import guide](../sql-import-preview.md)
- Add bounded static rendering for PowerShell, batch, Dockerfile, ignore files, textual JSONB, known lockfiles and XML property lists. Finder availability depends on the type resolved by macOS and the selected provider. [Preview format matrix](../shell-preview-matrix.md)
- Declare PowerShell and batch preview types on macOS and use a narrow TOML fallback that preserves unrelated configuration-file associations. The package records observed type matches and source-file editor defaults. See the preview matrix for format-specific Finder evidence.

The Apple silicon DMG uses ad-hoc seals for the app and its Quick Look extension. Windows x64 and Ubuntu 26.04 x64 packages are unsigned. Verify the downloads against `SHA256SUMS`. [Installation and rollback](../install-2.18.5.md)
