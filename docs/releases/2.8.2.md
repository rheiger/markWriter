## MarkWriter 2.8.2

MarkWriter detects changes to local Markdown files while they are open, including in background tabs. You can reload from disk or save your edits to a separate file. Saving checks that the original file still matches the last saved version. Automatic detection covers local files up to 1 MiB. The save check also applies to larger files. [External-file changes](https://github.com/rheiger/markWriter/issues/82)

The installation guide covers Windows x64 machine-wide upgrade and manual rollback to 2.7.5, including retrying removal after the bundled preview DLL is released and keeping the user profile. [Windows rollback](https://github.com/rheiger/markWriter/issues/84)

Verify downloads against `SHA256SUMS`. The macOS app and Quick Look extension use ad hoc integrity seals. The Windows installer is unsigned. [Installation, removal and rollback](https://github.com/rheiger/markWriter/blob/v2.8.2/docs/install-2.8.2.md)
