# MarkWriter 2.22.2

MarkWriter now renders a bounded subset of fenced PlantUML sequence and class diagrams offline. WYSIWYG and Preview display the diagrams, and HTML export embeds them as static SVG. The original Markdown remains editable. Missing themes, external includes, unsupported syntax and diagrams that exceed the rendering limits remain readable as source. See the examples and exact grammar in the [supported Markdown guide](https://github.com/rheiger/markWriter/blob/v2.22.2/docs/supported-markdown.md).

On Apple silicon, Finder Quick Look renders the same subset with MarkWriter open or closed. Its four-diagram limit is shared with the other supported diagram types. A renderer timeout falls back to readable source and the next file can still be previewed.

This cumulative release includes the app and export slice assigned to 2.22.1 and the Finder slice assigned to 2.22.2. The macOS app and Quick Look extension carry ad-hoc integrity seals. The Windows x64 and Ubuntu 26.04 x64 packages are unsigned. Verify the package against `SHA256SUMS` before installation.
