MarkWriter 2.7.0 renders offline DBML entity-relationship diagrams in Markdown Preview, WYSIWYG and self-contained HTML export. Finder Quick Look now renders Markdown tables, emphasis, inline code and link labels, supports more Mermaid diagrams, and highlights supported standalone Bash, Python, Makefile, SQL and structured text.

Download the Apple silicon macOS DMG, Windows x64 NSIS installer or Ubuntu 26.04 x64 DEB. Optional Windows Explorer, Ubuntu Sushi and KDE Dolphin Markdown previews have separate downloads. The Mac app and extension use ad hoc seals. The Windows installer and preview DLL are unsigned. Verify downloads against the attached SHA256SUMS and read the installation guide.

SQL DDL import, native PDF export and app-controlled update installation remain open. See the [changelog](https://github.com/rheiger/markWriter/blob/v2.7.0/CHANGELOG.md), [DBML syntax guide](https://github.com/rheiger/markWriter/blob/v2.7.0/docs/dbml-2.7.md) and [installation and rollback guide](https://github.com/rheiger/markWriter/blob/v2.7.0/docs/install-2.7.0.md).
