MarkWriter 2.7.3 improves highlighting for long, explicitly labeled SQL fences in both editors, Preview, self-contained HTML export and Finder Markdown previews. SQL DDL import provides more specific file, dialect and unsupported-syntax messages. The importer remains an experimental offline subset of PostgreSQL and SQLite. [SQL import guide](https://github.com/rheiger/markWriter/blob/v2.7.3/docs/sql-import-preview.md)

On Apple silicon macOS, the bundled Finder extension adds preview registrations for `.h`, `.cpp`, `.js` and `.css`, and can color literal YAML fallback. The preview registrations leave editor associations to macOS. [Format and platform matrix](https://github.com/rheiger/markWriter/blob/v2.7.3/docs/shell-preview-matrix.md)

The Mac removal tool previews a path-scoped, reversible move by default. Use it with the install guide to remove or restore a verified copy while keeping your documents and profile. Update discovery remains manual. [Install, removal and rollback](https://github.com/rheiger/markWriter/blob/v2.7.3/docs/install-2.7.3.md)

Download the Apple silicon macOS DMG, Windows x64 installer or Ubuntu 26.04 x64 DEB. Explorer, Sushi and Dolphin preview add-ons are separate downloads. The Mac app and extension have ad hoc seals. Windows packages are unsigned. Verify downloads against SHA256SUMS.
