MarkWriter 2.7.2 adds offline syntax highlighting for explicitly labeled TOML fences in both editors, Preview and HTML export. On Apple silicon macOS, Finder Quick Look also highlights TOML fences and standalone `.toml` source without adding an editor association. [#68](https://github.com/rheiger/markWriter/issues/68)

This release also previews offline PostgreSQL and SQLite DDL import. Use **Insert → Diagram → Import SQL DDL…** (directly under **Insert** on macOS) to review warnings and edit the generated DBML before appending. See the supported subset and examples. [SQL import preview](https://github.com/rheiger/markWriter/blob/v2.7.2/docs/sql-import-preview.md)

Download the Apple silicon macOS DMG, Windows x64 installer or Ubuntu 26.04 x64 DEB. Optional desktop preview add-ons have separate downloads. The Mac app and extension use ad hoc seals. Windows packages are unsigned. Verify downloads against SHA256SUMS.
