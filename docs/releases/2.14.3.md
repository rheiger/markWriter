# MarkWriter 2.14.3

Choose **Skip This Release** to suppress automatic notices for one version or **Remind Me Later** to defer the notice for 24 hours. MarkWriter remembers the choice across restarts. **Help → Check for Updates** still checks for the latest stable release and offers the matching manual download.

This iteration adds verification fixtures for signed update manifests and an isolated macOS replacement and rollback tool for qualification. App-controlled installation remains under development.

See [installation, upgrade and rollback](../install-2.14.3.md) for the platform-specific packages and instructions.
