## MarkWriter 2.7.4

- The Windows x64 installer uses Program Files and includes read-only Markdown previews for File Explorer. It retires recognized older MarkWriter installs and registrations from the current user profile.
- Open `.md` and `.markdown` directly from Explorer. A running MarkWriter window opens the selected document in a tab.
- New files start at the top. Reopening a file restores its remembered scroll position and editor mode.

Windows keeps existing default-app choices. To make MarkWriter the default, select it in **Open with** or Windows **Default apps**. PowerToys Peek remains a separate utility.

Verify downloads against `SHA256SUMS`. The macOS app and extension are ad hoc sealed and Windows packages are unsigned. See the [installation, removal and rollback guide](https://github.com/rheiger/markWriter/blob/v2.7.4/docs/install-2.7.4.md).
