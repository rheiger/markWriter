MarkWriter 2.7.1 fixes two Finder Quick Look issues. Finder can preview `.jsonl` files with the same record formatting and syntax colors as `.ndjson`. Larger supported code blocks and source files retain syntax highlighting within the expanded Quick Look limits.

Download the Apple silicon macOS DMG, Windows x64 installer or Ubuntu 26.04 x64 DEB. Optional desktop preview add-ons have separate downloads. The Mac app and extension use ad hoc seals. Windows packages are unsigned. Verify downloads against SHA256SUMS.

DBML diagrams are available from fenced Markdown. SQL DDL import remains open in [#42](https://github.com/rheiger/markWriter/issues/42).
