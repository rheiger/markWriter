## MarkWriter 2.11.2

- Import and export portable JSON profiles in Settings. Import loads a draft you can review before applying. Export saves the current draft, including edits you have yet to apply. [Portable settings](https://github.com/rheiger/markWriter/issues/99)
- Highlight explicitly labeled Java, Perl, AWK and CMake fences in the Markdown editor, WYSIWYG, Preview and offline HTML export. [Additional languages](https://github.com/rheiger/markWriter/issues/98)
- Finder Quick Look previews `.tsx` and `.mjs` files on Apple silicon. [Finder source previews](https://github.com/rheiger/markWriter/issues/90)
- Preview and offline HTML export highlight larger TOML fences within documented limits, with literal fallback for dense or oversized blocks. [Larger TOML fences](https://github.com/rheiger/markWriter/issues/94)

Download the Apple silicon macOS DMG, Windows x64 installer or Ubuntu 26.04 x64 DEB. Verify the package against `SHA256SUMS`. The macOS application and Quick Look extension use ad hoc integrity seals. The Windows installer is unsigned. [Installation, removal and rollback](https://github.com/rheiger/markWriter/blob/v2.11.2/docs/install-2.11.2.md)
