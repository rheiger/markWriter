Experimental **Rust/Tauri** MarkWriter prerelease. Historical Python/Qt releases remain unchanged.

- Offline embedded DOT/Graphviz in Preview and opaque WYSIWYG nodes, with editable canonical fences, source folds/search, block correspondence and sanitized static SVG/HTML export. Mermaid, tables and existing document ownership/recovery controls remain supported.
- DOT uses bundled Viz3.31.0 / Graphviz16.1.0 in a killable worker. Limits:64KiB source,2MiB SVG,2s layout plus5s startup;32 queued jobs. No hard WASM memory bound is claimed. Images/resources/links/HTML labels and unsupported attributes produce recoverable source-preserving errors. See the supported Markdown guide and notation ADR for the deliberate subset.
- Production package targets: macOS Apple Silicon DMG/app, Windows x64 NSIS and Ubuntu 26.04x64 DEB. Exact tested OS/WebView baselines, source SHA, build run and signing state are recorded per asset. Other platforms are not supported by inference.

**Unsigned experimental distribution.** macOS ad-hoc signing is not notarization/Developer ID; Windows has no Authenticode signature. Consult the manifests and acceptance report for the exact installation/launch paths tested. Keep OS protections enabled; report any blocked launch. Review [installation, profiles, upgrade and rollback](https://github.com/rheiger/markWriter/blob/v2.1.0-alpha2/docs/install-alpha2.md), verify SHA256SUMS and read the bundled third-party notices. `MARKWRITER_PROFILE_DIR` can select a new absolute isolated profile without changing native document dialogs.

Recovery does not autosave original files or guarantee final unflushed keystrokes after abrupt termination. Undo history does not survive restart. DBML#33, PlantUML#31, draw.io#5, logs#29, independent windows and plugins remain deferred. This prerelease is not promoted to stable/latest and has no automatic updater rollout.
