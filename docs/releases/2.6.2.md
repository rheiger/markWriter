MarkWriter 2.6.2 is a preliminary release with a macOS Finder Quick Look extension. Select a supported file and press Space. Markdown previews support syntax highlighting, Mermaid flowcharts and DOT graphs. Finder also previewed JSON, NDJSON, YAML and XML on the tested Mac. Finder showed file info for `.jsonl`.

The arm64 macOS package uses ad hoc signatures. Windows x64 and Ubuntu 26.04 x64 packages are also provided. See the [install, manual Quick Look registration and rollback guide](https://github.com/rheiger/markWriter/blob/v2.6.2/docs/install-2.6.2.md) or the attached `INSTALL-UPGRADE-ROLLBACK.md`. Verify package hashes with `SHA256SUMS`.
