Experimental Rust/Tauri MarkWriter alpha3 candidate. Publication and platform qualification depend on the recorded final-source gates; this document alone does not announce a release.

- Theme-consistent toolbar and explicit View→Theme Auto/Light/Dark choices synchronized with Settings, including live Auto appearance updates for editor/diagram themes.
- Shared ordinary-code syntax highlighting in Markdown source, WYSIWYG and Preview, with local token CSS in self-contained HTML export. All16 requested variants are bundled; explicit language/alias wins, conservative unlabeled detection falls back to plain. View and toolbar share a saved default-on toggle. Canonical Markdown, undo, folds, selection and independent fonts remain view-independent.
- Recognizable blue/white MarkWriter icon in native package assets. Whole-bundle ad-hoc macOS sealing must pass strict verification. This provides integrity, not trusted signing/notarization. Windows remains unsigned.

Code presentation bounds:4Ki UTF-16 units per explicit block,2Ki per automatic block/line;16Ki/64blocks/4automatic blocks per document rebuild. Excess stays plain with all source retained. These are work/input limits, not a hard CPU deadline. See [implementation and acceptance](../highlighting-theme-alpha3.md) and [installation, profiles and rollback](../install-alpha3.md).
