# MarkWriter 2.19.3

- Open local Markdown files from GNOME Files on Ubuntu 26.04. File-manager requests go to the matching editor profile and use the existing document ownership checks for unsaved tabs. [#169](https://github.com/rheiger/markWriter/issues/169)
- Add repeatable Finder qualification fixtures for large PowerShell and structured JSON, JSON Lines, XML and YAML previews. [#164](https://github.com/rheiger/markWriter/issues/164) · [#170](https://github.com/rheiger/markWriter/issues/170)

The Apple silicon DMG carries ad-hoc seals for the app and its Quick Look extension. Windows x64 and Ubuntu 26.04 x64 packages are unsigned. Verify the downloads against `SHA256SUMS`. [Installation, removal and rollback](../install-2.19.3.md)
