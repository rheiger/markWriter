# Quick Look experiment after Xcode license acceptance

Xcode 27.2 builds an unsigned arm64 Quick Look preview extension on macOS 27.2. This follows the earlier [license failure](2.6-quicklook-feasibility.md). The extension and its common-format declarations live in an isolated build target. Production bundling remains gated on the installed test.

The renderer reads at most 1 MiB plus a size sentinel through a nonblocking descriptor. It rejects symlinks and verifies a regular file on the same descriptor before reading. The reply escapes all document text and uses a static HTML page with a content security policy that denies scripts and network resources.

| Input | Experimental rendering |
| --- | --- |
| `.md`, `.markdown` | Headings, paragraphs and fenced code. Inline formatting, links, images, diagrams and math stay as source. |
| `.json` | Indents the original tokens with a depth limit of 32 and a formatted text limit of 2 MiB. Duplicate keys and numeric spelling are preserved. Invalid input and limit failures use literal text. |
| `.jsonl`, `.ndjson` | Formats individual records and identifies malformed lines. Limits are 2,000 lines and 2 MiB of formatted text. On the tested host, `.jsonl` resolves to a dynamic UTI and `.ndjson` resolves to `public.ndjson`. The experimental extension declares only `public.ndjson` for this format. |
| `.xml` | Formats a compact, attribute-free element tree with up to 64 levels and 10,000 elements. DTDs, entity references, mixed content, declarations and other unsupported XML use literal text. External entity resolution is disabled. |
| `.yaml`, `.yml` | Literal text with an explanation. Structured YAML formatting and syntax colors remain open. |

The experimental `Info.plist` uses existing UTIs. Apple advises using Quick Look extensions for custom file formats the app defines. The presence of standard format declarations, including those for JSON and XML which already have system providers on this host, does not establish selection or shipping eligibility. [Apple’s guidance](https://developer.apple.com/documentation/technologyoverviews/convenience)

## Reproduce the unsigned build and renderer tests

With a licensed Xcode selected for the process, use a fresh absolute output directory. The build helper suppresses the linker’s ad hoc signature so the resulting extension stays within the unsigned test scope.

```sh
native/quicklook/build-experiment.sh /absolute/path/to/new-output-directory
cat native/quicklook/PreviewRenderer.swift native/quicklook/SimpleXMLFormatter.swift \
  native/quicklook/JSONFormatter.swift native/quicklook/SafeFileReader.swift \
  native/quicklook/tests/main.swift | xcrun swift -
```

The Swift interpreter tests exercise rendering, output and nesting limits, malformed records, Unicode, CRLF, unsafe XML, symlinks, FIFOs and oversized reads. The macOS host killed a direct launch of the unsigned extension executable. Apple silicon requires a valid code signature to execute native arm64 code. Finder selection, sandbox behavior, file preservation during OS preview, provider coexistence, and upgrade/uninstall behavior still require installed tests. [Apple platform security](https://support.apple.com/guide/security/rosetta-2-on-a-mac-with-apple-silicon-secebb113be1/web)
