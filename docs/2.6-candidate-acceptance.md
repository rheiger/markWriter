# 2.6 native-integration candidate — qualification in progress

This is an unreleased candidate, not a replacement of 2.5.1. No tag, release, latest change or update-feed activation is authorized. Publication is blocked in release policy and the draft workflow. Candidate Mac packaging deliberately omits OS signing, including explicit ad-hoc whole-bundle sealing; the compiler/linker signature is inspected only. This differs from the sealed 2.5.1 release and requires a separate signing/release instruction before distribution qualification.

Native menus and bounded regex are core; actual Quick Look is blocked by the unaccepted Xcode license at the first unsigned prototype build. No account/license/signing changes were made. JSON/XML provider collisions remain unproved; structured previews and Windows/Linux shell providers remain deferred. Update discovery is implemented separately from secure installation, which has no installed A→B proof and remains deferred. See [Quick Look evidence](2.6-quicklook-feasibility.md), [regex contract](regex-search-2.6.md), [update limitations](2.6-updater.md).

Automated and isolated native workflows are in progress. Exact commit/CI/package and preservation evidence will be added after gates finish. Do not infer full platform acceptance from compilation or app launch.
