## Limits and next work

macOS has a strict ad-hoc seal, without Developer ID trust or notarization; Windows is unsigned. Browser quarantine, broader shell/cache/upgrade visuals and untested OS baselines remain unqualified. Linux support here is Ubuntu 26.04 x64; see actual platform manifests for OS/WebView versions.

Highlighting uses input/work bounds rather than a hard lexer deadline. An adversarial 14 Ki Python f-string observation took 201 ms before plain fallback; cancellable/fair highlighting belongs in the next round. Actual WYSIWYG edits can normalize Markdown syntax; arbitrary OS text services remain separately unqualified. No PDF, DBML/DDL, PlantUML, draw.io, graphical designers, plugins, standalone-format editing or independent windows are added here.

See the [next-round proposal](next-round-after-2.5.1.md) and [installation/rollback guide](install-2.5.1.md). Backlog proposals are not new implementation authority.
