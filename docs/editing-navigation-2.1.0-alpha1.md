## Delivered behavior

- Current-tab Find/Replace in Markdown and WYSIWYG: count, next/previous with wraparound, case/whole-word, current replacement and one-step Replace All. Cmd/Ctrl+F, macOS Cmd+Shift+H / other platforms Ctrl+H, Edit menu, Enter/Shift+Enter and Escape use the real engines. Query/highlights do not move the editing selection until navigation. Markdown includes folded source; rendered scope stays inside text blocks, spans marks and excludes atoms. Search source explicitly accesses diagram internals.
- View-only soft-wrap arrows, persisted Settings toggle, source/copy/caret preservation; adaptive 5×5 table grid with pointer grow/shrink, keyboard sizing, area/dimensions, viewport cap and numeric controls to 40×40. Row counts include the header.
- Selected multiline Code creates one safe fence / sibling rendered code block, with one Undo; Body safely unwraps fenced/indented source code. Source list actions format selected lines without deleting their text. Explicit formatting ends at the transformed content, rather than document end. WYSIWYG Markdown-prefix typing/paste stays literal, including extension escaping. Fresh New/Open starts at the beginning; existing/restored tabs keep their own navigation.
- Parser-owned UTF-16 correspondence maps power bidirectional content-anchor scrolling, source caret/range overlays and native Preview click/drag selection. Entity/escape/Unicode, marked/link/table/list text map locally. Diagram/image/syntax positions use a visibly dashed containing-block fallback. Passive scroll keeps the caret and folds unchanged. Sync defaults on and persists; off permits independent navigation. Interactive Preview link labels select/navigate source, with destination tooltips; exported links remain active.

See [ownership ADR](adr-preview-correspondence.md), [Markdown/search/picker conventions](supported-markdown.md) and the [complete #28 disposition](editing-28-disposition-2026-11-06.md). Canonical bytes, per-tab histories, captured I/O ownership, independent fonts and recovery rules remain the controlling contracts.

## Review and limits

One implementer reviewed correctness, ownership/lifecycle, encoding/security, readability and performance. Review reproduced and fixed source toolbar reading a retained rendered selection, WebKit focus scroll reset, repeated-string bulk edits, the source list deletion defect and native URL dragging interfering with Preview label selection. There was no independent reviewer or competing edit agent.

- Exact inverse mapping is available only for representable text. Syntax/atoms and unsupported token transformations use documented local block correspondence; clipping/top/bottom limits can prevent identical viewport positions.
- WYSIWYG Code combines sibling text blocks. It deliberately does not flatten across separate cells/list parents; format inside each container.
- Search is literal/current-document; rendered matches stop at block/atom/hard-break boundaries. No regex or project search. Very large replace operations remain synchronous; measured 1–2MB fixtures complete without losing folds/source.
- Native macOS IME candidate-window behavior is not proven by Chromium composition. Windows/Linux OS Open/Save/Export dialogs, signing and distribution packages remain separate release acceptance.
- Existing large frontend chunk and unused Rust test-import warnings remain. Windows driver log records a WebView shutdown class-unregistration1412 message; Linux Xvfb logs accessibility-bus/DRI3 warnings. Neither fails the22-case results. No new dependency was needed for the core.
- DOT/DBML/PlantUML were actually attempted after core acceptance and independently deferred; see the [offline spike](notation-offline-spike-2026-11-06.md). #10 retains deferred menu scope; #5 draw.io and #29 logs remain backlog. Independent windows/plugins/broad preferences/graphical designers/database connections are outside this increment.
