# Tagged Apple-silicon DMG qualification

[Build 46133829847](https://github.com/rheiger/markWriter/actions/runs/46133829847) produced the 15,166,859-byte MarkWriter 2.22.2 DMG from tag commit `582eb7114b9bcbf4a3179492011ef0a5be976311`. Its SHA-256 is `2361f0216f37dd2e94d56e6189245fc13ffad9c9d4f63a2e594b76ac6d8924f4`. On arm64 macOS 27.2.1 (26B131), the app and Quick Look extension passed strict ad-hoc seal verification from read-only mounts. The package remained uninstalled.

All seven multiblock documents and eleven single-block controls passed in direct WKWebView. The first and warm sequences took 626 and 405 ms. The representative class took 424 ms. A sequence after rejected inputs took 423 ms. Peak resident memory of the single-block probe process reached 163,512,320 bytes. WebKit children and Finder display overhead fall outside these measurements. The loopback server received its positive control only. All eight synthetic Markdown fixture hashes matched before and after. The installed 2.19.3 registration record, directory inode and executable and renderer hashes also matched. The actual Finder and editor observations are from the corrected 2.21.1-metadata candidate. The tagged DMG received the direct checks reported here. Comparing every file in the two Quick Look extensions found identical renderer JavaScript and CodeResources. Info.plist changes only CFBundleShortVersionString and CFBundleVersion to 2.22.2. Both provider signatures verified strictly. After removing signatures from disposable copies with `codesign --remove-signature`, `cmp -s` found byte-identical arm64 executables. The unsigned executable SHA-256 is `ebab3a858daa9053d5ef05e86d3047bedc70f6facc6e0e3794224435a6efb479`. Entitlements match. This comparison covers the Finder provider.
